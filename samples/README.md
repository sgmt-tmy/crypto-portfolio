# samples

取引所CSVの**ダミー**。取り込み処理の開発とテスト用。公開リポジトリなので、**実在の値(氏名・ID・金額・日付と数量の組み合わせ)を置かない**(公開リポジトリの方針)。

| ファイル | 内容 | 注意 |
| --- | --- | --- |
| `gmo/2025_trading_report.csv` | GMOコインの取引報告書 | UTF-8(BOM付き)。`精算区分`で行の種類が分かれる(取引所現物・販売所・日本円入出金・手数料返金・預入/送付)。日時は `2025/01/02 21:45` 形式 |
| `bitbank/annual_trade_report.csv` | bitbankの年間取引報告書(通貨ごとの年間集計) | 先頭に氏名の行がある(ダミー)。取り込みでは氏名を読まない |
| `bitbank/asset_records.csv` | bitbankの資産推移(日ごとの通貨別残高、横持ち) | 新しい日付が上。通貨の列は増えるので列名を固定にしない |
| `bitbank/user_spot_trades_archived-*.csv` | bitbankの約定履歴(現物) | 手数料は円建ての符号付き(maker=負)。時刻の小数部の桁数が不定。**DOGEの2025-08-03の約定はあえて欠けている**(年間集計・資産推移との突き合わせで警告が出ることの確認用) |
